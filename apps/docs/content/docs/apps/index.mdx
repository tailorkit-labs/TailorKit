TailorKit apps add focused functionality to a product that already uses
TailorKit. They run separately from the host product, but render with the
host's approved components and receive only the context and actions the host
chooses to expose.

You can read this section without setting up a host product. To build or preview
an app, the product team must first complete
[Installation](/docs/integrate/installation) and keep the host running. Ask them
for its TailorKit API URL.

## How app development works

The host product publishes a typed contract. Run `pnpm generate` in your app
project to turn that contract into local TypeScript bindings. Build your views
with those bindings, then preview or deploy the app through the TailorKit CLI.

When you need a new component, view, context field, or trusted action, ask the
team that owns the host product to expose it. The host remains the authority
for its data, permissions, and UI capabilities.
