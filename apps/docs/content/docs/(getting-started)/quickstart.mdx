Create a small app for the `/` view and preview it in your host product.

<Callout title="Before you start">
  Complete [Installation](/docs/installation) and keep your host app running. Its TailorKit handler
  must be available at `/api/tailorkit`.
</Callout>

<Steps>
<Step>

### Scaffold the app

Create the app beside your host project. Replace the host URL if your app uses
a different port or handler path.

```sh
pnpm dlx @tailorkit/cli init . \
  --name hello-tailorkit \
  --host http://localhost:3000/api/tailorkit
cd hello-tailorkit
```

This creates a separate app project with a default view.

</Step>
<Step>

### Generate host bindings

Keep the host app running, then fetch its current schema:

```sh
pnpm generate
```

This creates `src/tailorkit.gen.ts`, which contains typed bindings for the
views, slots, and capabilities exposed by the host. Do not edit this file.

</Step>
<Step>

### Implement the view

Replace `src/views/default.tsx` with:

```tsx title="src/views/default.tsx"
import { createView } from "@tailorkit/app";
import { Box } from "#tailorkit";

const view = createView("/", {
  component: HomeView,
});

function HomeView() {
  return <Box padding="md">Hello from TailorKit!</Box>;
}

export default view;
```

`Box` is rendered by the host, so it uses the host product's implementation and
styles. The generated `src/client.ts` already registers this view.

</Step>
<Step>

### Link and deploy the app

Authenticate the CLI with the host, then make the first deployment:

```sh
pnpm exec tailorkit login
pnpm deploy
```

When prompted, create the TailorKit app. The deployment records its `appId` in
`tailorkit.config.ts`, which the preview command uses to start a session.

</Step>
<Step>

### Preview the app

Start a remote preview session:

```sh
pnpm exec tailorkit preview
```

The CLI keeps Vite in watch mode and prints a host preview link. Open the link
while signed in to the host and choose **Accept preview**. The app then appears
in the host's normal app list and renders in `Slot`. Successful builds are
uploaded in bounded chunks; a failed build leaves the last successful preview
running. Stop the CLI to end the session immediately.

</Step>
</Steps>

You now have a sandboxed app rendering a host-owned component. When the host
contract changes, rerun `pnpm generate` before continuing development.
