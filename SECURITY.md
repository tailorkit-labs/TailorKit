# Security policy

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Use GitHub's private vulnerability reporting to send a report:

[Report a vulnerability](https://github.com/tailorkit-labs/TailorKit/security/advisories/new)

Include the affected package or application, the impacted version or commit,
steps to reproduce the issue, and the potential impact. Do not include secrets,
personal data, or customer data in the report.
